# Human Evaluation of RippleBench Pipeline

## Overview

We conduct four human evaluation experiments on Amazon Mechanical Turk to validate the core components of the RippleBench pipeline: RAG-based semantic ranking, fact-grounded question generation, article-to-topic specificity, and topic extraction accuracy. Each experiment is run on two dataset variants.

### Dataset Variants

**WMDP Subsampled.** We subsample from the full RippleBench-Bio dataset, which contains specialist biomedical topics derived from the WMDP benchmark. Because these topics are often too difficult for non-expert crowd workers (e.g., "Polyvinylpyrrolidone", "Cyclin-dependent kinase"), we use an LLM-based difficulty filter (Claude Sonnet, temperature=0) to classify each question as EASY, MEDIUM, or HARD based on whether a non-specialist could reasonably answer it. Only EASY-classified questions are retained. This subsampling ensures that workers can meaningfully engage with the content while preserving the original RippleBench-Bio topic distribution and distance structure.

**High-School (Simple).** We construct a parallel dataset of 100 common-knowledge base topics spanning 10 subject areas (History, Biology, Geography, Physics, Chemistry, Civics, Famous People, Technology, Earth Science, Math) with 10 topics each. For each base topic, we run the same RippleBench pipeline: RAG-based neighbor retrieval (k=1001 nearest Wikipedia articles), fact extraction via Claude Sonnet, and multiple-choice question generation at 13 sampled distances [1, 5, 10, 25, 50, 100, 150, 200, 250, 350, 500, 750, 1000]. This produces 5,685 questions across 1,137 topic-distance pairs. By using topics that are broadly familiar (e.g., "Photosynthesis", "World War II", "Gravity"), we ensure that crowd workers can evaluate the pipeline without domain expertise.

Both variants are evaluated across the same four experiments with 3 independent workers per task.

## Experiment Descriptions

### Experiment 1: Semantic Ranking Validation

**Question:** Does the RAG-based semantic ranking align with human perception of topic relatedness?

**Design:** Each task presents a base topic and two neighbor topics drawn from different rank buckets in the base topic's RAG neighbor list. Workers are asked: "Which of these two topics is more closely related to the base topic?" Response options are: Topic A, Topic B, Equally related, or I don't know this topic. The display order of Topic A and Topic B is randomized to control for position bias.

**Sampling:** We define 6 rank buckets: (1-10), (10-50), (50-100), (100-250), (250-500), (500-1000). Tasks are stratified across all 15 pairwise bucket combinations, with ~16-17 tasks per pair, for a total of 250 tasks.

**What this validates:** If the RAG embedding distance is a meaningful proxy for semantic relatedness, workers should consistently identify the lower-ranked (closer) topic as more related, particularly when the rank gap is large.

### Experiment 2: Question Quality (Fact-Grounded MCQ)

**Question:** Are the generated multiple-choice questions answerable, and does providing extracted facts improve accuracy?

**Design:** Each task presents a 4-option multiple-choice question generated by the RippleBench pipeline, with a 5th "I don't know" option. Tasks are split into two conditions: Condition A (with facts) displays the extracted facts about the topic alongside the question; Condition B (without facts) shows only the question. Workers answer the question to the best of their ability.

**Sampling:** 250 tasks are stratified across 8 distance buckets [1-5, 6-25, 26-50, 51-100, 101-200, 201-350, 351-600, 601-1000], with ~31 questions per bucket. Within each bucket, half are assigned to with-facts and half to without-facts. Conditions are interleaved to ensure balanced presentation order.

**What this validates:** (1) Whether the generated questions are well-formed and answerable by humans. (2) Whether the extracted facts contain sufficient information to answer the questions (the gap between with-facts and without-facts accuracy). (3) Whether question difficulty varies with semantic distance from the base topic.

### Experiment 3: Article-to-Topic Matching

**Question:** Is the extracted article text specific enough to uniquely identify its topic?

**Design:** Each task presents a text excerpt (extracted facts) about a topic and 4 topic name options. One option is the correct topic; the other 3 are distractors sampled from 100-250 ranks away in the same base topic's RAG neighbor list. Workers select which topic the article is about. Option display order is randomized.

**Sampling:** 250 tasks are drawn from the dataset, each using a distinct topic. Distractors are chosen to be semantically adjacent (from the same neighborhood) but not identical, making the task non-trivial.

**What this validates:** Whether the fact extraction step produces text that is specific enough to distinguish a topic from its semantic neighbors. High accuracy indicates that the extracted facts capture topic-identifying information rather than generic domain content.

### Experiment 4: Question-to-Topic Extraction

**Question:** Can humans identify which base topic a generated question belongs to?

**Design:** Each task presents a generated question and 4 topic options. One is the correct base topic that the question was generated from; the other 3 are randomly sampled base topics as distractors. Workers select which topic the question is most likely about. Option display order is randomized.

**Sampling:** For the WMDP variant, 200 tasks are sampled from the WMDP question pool. For the high-school variant, 100 tasks are generated (one per base topic), using a question at the lowest available distance from the base topic.

**What this validates:** Whether the generated questions maintain a clear semantic link to their originating topic. High accuracy confirms that the question generation step produces topic-relevant content rather than generic or ambiguous questions.

## Results

### Experiment 1: Semantic Ranking Validation

Does the RAG-based neighbor ranking reflect human intuitions about topic relatedness? We test this by showing workers two topics at different ranks and asking which is closer to a base topic. If the ranking is meaningful, workers should reliably identify the lower-ranked topic.

| | High-School | WMDP Subsampled |
|---|---|---|
| Correct | 43.1% | 61.7% |
| Incorrect | 17.2% | 14.8% |
| Equal | 21.3% | 16.8% |
| Unknown | 18.4% | 6.7% |

**High-School:**

![Exp 1 High-School](https://anonymous.4open.science/r/ripple_bench_rebuttals-3FBF/MTURK-exp-with-results/results/plots/high_school/exp1_ranking_heatmap_2026-04-02_211725.png)

**RippleBench-WMDP Subsampled:**

![Exp 1 WMDP](https://anonymous.4open.science/r/ripple_bench_rebuttals-3FBF/MTURK-exp-with-results/results/plots/wmdp_subsampled/exp1_ranking_heatmap_2026-04-02_211706.png)

Accuracy depends strongly on which bucket pairs are being compared. When one topic is very close to the base (rank 1-10) and the other is distant, workers achieve 85-97% accuracy on both datasets. When both topics are distant from the base (e.g., 100-250 vs 500-1000), accuracy drops to chance (~50%), as workers cannot distinguish degrees of unrelatedness. The right panel of each heatmap shows the equal+unknown opt-out rate, which is highest for adjacent bucket comparisons (workers perceive the topics as equally related) and for distant-vs-distant comparisons (workers are unfamiliar with the topics). The WMDP dataset shows higher overall accuracy (61.7% vs 43.1%) and lower unknown rates (6.7% vs 18.4%), likely because the difficulty filter selected for more recognizable topics.

**Takeaway:** Human semantic similarity judgments align with RAG embedding rankings at coarse granularity, validating the use of bucketed distance ranges rather than fine-grained rank positions.

### Experiment 2: Question Quality

Are the questions generated from the extracted facts well-constructed? We test this by checking whether providing the source facts substantially improves worker accuracy on the generated questions. A large gap between the with-facts and without-facts conditions indicates the questions are genuinely grounded in the extracted content.

| | High-School | WMDP Subsampled |
|---|---|---|
| Overall accuracy | 58.5% | 60.8% |
| With facts accuracy | 71.0% | 75.8% |
| Without facts accuracy | 46.3% | 47.6% |
| With facts IDK rate | 1.3% | 2.6% |
| Without facts IDK rate | 24.6% | 26.8% |

**High-School:**

![Exp 2 High-School](https://anonymous.4open.science/r/ripple_bench_rebuttals-3FBF/MTURK-exp-with-results/results/plots/high_school/exp2_accuracy_and_idk_2026-04-02_211725.png)

**RippleBench-WMDP Subsampled:**

![Exp 2 WMDP](https://anonymous.4open.science/r/ripple_bench_rebuttals-3FBF/MTURK-exp-with-results/results/plots/wmdp_subsampled/exp2_accuracy_and_idk_2026-04-02_211706.png)

Both datasets show a consistent ~25 percentage point accuracy gap between the with-facts and without-facts conditions, stable across all distance buckets. The IDK rate tells a complementary story: workers almost never select "I don't know" when given facts (1-3%), but do so 25-27% of the time without facts. Accuracy does not degrade meaningfully with semantic distance in either condition, suggesting that question difficulty is determined by the topic's inherent familiarity rather than its distance from the base topic.

**Takeaway:** The extracted facts contain sufficient information to answer the generated questions. The large accuracy gap between conditions confirms that the questions are fact-grounded rather than trivially answerable from general knowledge alone.

### Experiment 3: Article-to-Topic Matching

Are the extracted facts specific enough to identify their topic? We test this by showing workers an article excerpt and asking them to pick the correct topic from 4 options, where the 3 distractors are drawn from the same semantic neighborhood. High accuracy means the facts capture topic-distinguishing content rather than generic domain information.

| | High-School | WMDP Subsampled |
|---|---|---|
| Overall accuracy | 90.1% | 85.2% |
| Random baseline | 25% | 25% |

Workers can reliably match extracted article text to the correct topic, with accuracy remaining high and flat across all distance buckets. This holds even though distractors are drawn from the same semantic neighborhood (100-250 ranks away), making them topically plausible alternatives. The high-school dataset achieves slightly higher accuracy (90.1% vs 85.2%), likely because common-knowledge topics are more distinguishable to non-expert workers.

**Takeaway:** The fact extraction step produces text that is specific enough to uniquely identify topics, even among semantically similar alternatives. The lack of distance-dependent degradation confirms that fact quality is consistent across the neighbor ranking.

### Experiment 4: Question-to-Topic Extraction

Do the generated questions clearly belong to their source topic? We test this by showing workers a question and asking them to identify which of 4 topics it was generated from. High accuracy confirms that the question generation step preserves a clear semantic link to the originating topic.

| | High-School | WMDP Subsampled |
|---|---|---|
| Per-response accuracy | 84.6% | 95.8% |
| Majority-vote accuracy | 85.0% | 99.5% |
| Random baseline | 25% | 25% |

Workers can identify the base topic of a generated question with high accuracy on both datasets. The WMDP variant achieves near-perfect majority-vote accuracy (99.5%), indicating that the specialist questions maintain a very clear semantic link to their originating topic. The high-school variant is somewhat lower (85.0%), possibly because common-knowledge topics have more overlapping semantic content (e.g., a question about "DNA" could plausibly relate to "Evolution" or "Cell").

**Takeaway:** The question generation step produces topic-relevant content. The high accuracy confirms that generated questions can be reliably traced back to their source topic, supporting the validity of topic-based evaluation in RippleBench.

## Summary

Across all four experiments and both dataset variants, the human evaluation results validate the core components of the RippleBench pipeline:

1. **Semantic ranking is meaningful** — when one topic is clearly close (rank 1-10) and the other distant, workers identify the closer topic with 85-97% accuracy; performance drops to chance only when both topics are far from the base, validating bucketed distance as the right granularity (Exp 1)
2. **Fact extraction is informative** — providing extracted facts boosts MCQ accuracy by ~25pp (71-76% with facts vs 46-48% without) and reduces "I don't know" responses from ~25% to under 3% (Exp 2)
3. **Facts are topic-specific** — workers match article text to the correct topic at 85-90% accuracy (vs 25% random baseline), even when distractors are drawn from the same semantic neighborhood (Exp 3)
4. **Questions are topic-grounded** — generated questions can be traced back to their source topic at 85-100% majority-vote accuracy (85% high-school, 99.5% WMDP) (Exp 4)

The consistency of these findings across both the specialist WMDP and common-knowledge high-school datasets provides evidence that the pipeline generalizes beyond any single domain.
